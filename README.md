## Project Overview

This project demonstrates an end-to-end modern analytics solution built using Microsoft Fabric, dbt, SQL, and Power BI.

The project transforms raw retail sales data into a clean Star Schema using dbt inside Microsoft Fabric and delivers an interactive executive dashboard in Power BI.

The goal was to simulate a real-world business intelligence solution that follows modern data engineering and analytics best practices.

---

## Business Objectives

The dashboard helps business users answer questions such as:

- How much have we sold?
- How many orders were placed?
- Which products generate the highest revenue?
- Which product categories perform best?
- How are sales performing compared to the previous year?
- What is the running sales trend over time?
